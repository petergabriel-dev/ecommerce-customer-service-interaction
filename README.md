# Ecommerce Customer Service Interaction — Analysis Notebook

Overview
- A Jupyter notebook (main.ipynb) to explore customer support data (Customer_support_data.csv).
- Goal: summarize agent/supervisor/manager performance and identify top performers.

What we did
- Loaded dataset with pandas and inspected basic info (df.head(), df.info(), df.isnull().sum()).
- Counted tickets/orders per agent (df['Agent_name'].value_counts() and df.groupby('Agent_name').size()).
- Built robust summaries that:
  - Use a unique Order/Ticket ID (if present) to avoid double counting via .nunique().
  - Produce per-agent, per-supervisor and per-manager counts (groupby + size/nunique).
- Produced supervisor-level breakdowns:
  - Top supervisors by count, supervisor→agent breakdown, manager→supervisor counts (if columns exist).
- Identified best-performing managers using multiple metrics:
  - Most orders handled (count or unique order id).
  - Fastest average resolution time (if resolution column exists).
  - Highest average satisfaction/rating (if rating column exists).
- Saved summary CSVs and plotted top lists:
  - per_agent_counts.csv
  - per_supervisor_counts.csv
  - top_managers_by_count.csv
  - Bar plots for top agents/supervisors (matplotlib/seaborn).

Files created

- Customer_support_data.csv — source data (expected in project root).
- per_agent_counts.csv, per_supervisor_counts.csv, top_managers_by_count.csv — outputs generated by the notebook.
